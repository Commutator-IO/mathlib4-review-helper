Generalises "a linear equivalence maps extreme points to extreme points" (`image_extremePoints`) from linear to semilinear equivalences, and drops the ordered-ring / additive-group assumptions it carried. To do so it adds semilinear versions of "a linear map sends segments (closed and open) onto segments", where the ring homomorphism $\sigma$ must preserve nonnegativity (resp. positivity). The old linear statements become one-line specialisations; the affine `image_segment` / `image_openSegment` only get shorter proofs.

## semilinear_image_extremePoints

For semirings $\mathbb{k}, \mathbb{k}'$ with partial orders, a ring isomorphism $\sigma : \mathbb{k} \to \mathbb{k}'$ (with inverse $\sigma'$, `RingHomInvPair` both ways), modules $E$ over $\mathbb{k}$ and $F$ over $\mathbb{k}'$, a $\sigma$-semilinear equivalence $f : E \to F$ (any `SemilinearEquivClass`) and $s \subseteq E$: if $0 < \sigma(a) \iff 0 < a$ for all $a$ (auto-proved by `simp`, e.g. for $\sigma = \mathrm{id}$), then
$$f(\operatorname{ext}_{\mathbb{k}} s) = \operatorname{ext}_{\mathbb{k}'} f(s).$$

**Proof.** Elementwise via surjectivity of $f$; unfold `mem_extremePoints` and rewrite open segments with `semilinear_image_openSegment`, then `simp` (injectivity of $f$).

## image_extremePoints

Statement unchanged ($f(\operatorname{ext} s) = \operatorname{ext} f(s)$ for a linear equivalence $f$), but now for a semiring $\mathbb{k}$ with a partial order and additive commutative monoids $E, F$ (previously an ordered ring and additive groups).

**Proof.** Now `semilinear_image_extremePoints` with $\sigma = \mathrm{id}$.

**Check.** It still sits in `section OrderedRing`, whose variables no longer contain any ordered-ring assumption; the section name is stale.

## semilinear_image_segment

For partially ordered semirings $\mathbb{k}, \mathbb{k}'$, $\sigma : \mathbb{k} \to \mathbb{k}'$ with `RingHomInvPair σ σ'`, a $\sigma$-semilinear map $f : E \to F$ (any `SemilinearMapClass`) and $x, y \in E$: if $0 \le \sigma(a) \iff 0 \le a$ for all $a$ (default `by simp`), then $f([x, y]_{\mathbb{k}}) = [f x, f y]_{\mathbb{k}'}$.

**Proof.** Both inclusions by hand: a point $a x + b y$ maps to $\sigma(a) f x + \sigma(b) f y$; conversely $a\, f x + b\, f y$ is the image of $\sigma'(a) x + \sigma'(b) y$, using $\sigma \sigma' = \mathrm{id}$ and the hypothesis to transfer $0 \le$ and $a+b=1$.

## semilinear_image_openSegment

Same as `semilinear_image_segment` for open segments, with the hypothesis $0 < \sigma(a) \iff 0 < a$: $f(\,]x, y[_{\mathbb{k}}) = \,]f x, f y[_{\mathbb{k}'}$.

**Proof.** Identical to the closed case, with strict inequalities.

## linear_image_segment

Simp lemma: for a linear map $f : E \to G$ (any `LinearMapClass`) over a partially ordered semiring, $f([a, b]) = [f a, f b]$.

**Proof.** `semilinear_image_segment` with $\sigma = \mathrm{id}$.

## linear_image_openSegment

Simp lemma: for a linear map $f$ (any `LinearMapClass`), $f(\,]a, b[\,) = \,]f a, f b[$.

**Proof.** `semilinear_image_openSegment` with $\sigma = \mathrm{id}$.

## image_segment

Statement unchanged: an affine map sends $[a, b]$ onto $[f a, f b]$.

**Proof.** Changed only: now `simp` with `segment_eq_image_lineMap` and `image_image` instead of an explicit `Set.ext`.

## image_openSegment

Statement unchanged: an affine map sends $]a, b[$ onto $]f a, f b[$.

**Proof.** Changed only: `simp` with `openSegment_eq_image_lineMap` and `image_image`.
