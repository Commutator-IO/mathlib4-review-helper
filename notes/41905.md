Adds inequalities for the relative rank of subfields / intermediate fields of a field $E$, where `relrank A B` $= [B : A \cap B]$ (rank of $B$ over $A \sqcap B$) and `relfinrank` is its `finrank` ($0$ when infinite). Main results: relrank is antitone in the first argument, and when $[B : A \cap B]$ is finite, adjoining $A$ (resp. a third field $C$ to both sides) does not increase it: $[A \sqcup B : A] \le [B : A \cap B]$ and $[B \sqcup C : (A \sqcup C) \cap (B \sqcup C)] \le [B : A \cap B]$. Each statement is proved for `Subfield` and transferred to `IntermediateField`.

## relrank_pos

For subfields $A, B$ of $E$: $0 < [B : A \cap B]$ (as a cardinal).

**Proof.** `rank_pos` (a field extension has positive rank).

## relfinrank_ne_zero_iff

`relfinrank A B` $\ne 0$ iff $[B : A \cap B] < \aleph_0$.

**Proof.** `relfinrank` is `toNat` of `relrank`, which is positive; `simp`.

## relrank_le_of_le_left

For subfields $A \le B$ and any $C$: $[C : B \cap C] \le [C : A \cap C]$ (tagged `@[gcongr]`).

**Proof.** Tower law `relrank_inf_mul_relrank_of_le`: $[C : A \cap C] = [B \cap C : A \cap B \cap C] \cdot [C : B \cap C]$, and the first factor is nonzero (`relrank_pos`), so `Cardinal.le_mul_left`.

## relfinrank_le_of_le_left

For subfields $A \le B$ and $C$ with `relfinrank A C` $\ne 0$ (i.e. $[C : A \cap C]$ finite): $\text{relfinrank } B\, C \le \text{relfinrank } A\, C$.

**Proof.** The existing divisibility `relfinrank_dvd_of_le_left` plus `Nat.le_of_dvd`.

## relrank_sup_left_le

For subfields $A, B$ with $[B : A \cap B] < \aleph_0$: $[A \sqcup B : A] \le [B : A \cap B]$ (precisely `A.relrank (A ⊔ B)`, whose base $A \sqcap (A \sqcup B)$ is $A$).

**Proof.** View $A$ as an $A \cap B$-algebra; $A \sqcup B$ is $A$ adjoin $B$ (proved via `toSubfield_inj` and `closure_union`), and `IntermediateField.adjoin_rank_le_of_isAlgebraic_right` bounds $[A(B) : A]$ by $[B : A \cap B]$, using finiteness of $B$ over $A \cap B$ for algebraicity.

## relfinrank_sup_left_le

`relfinrank` version: if `relfinrank A B` $\ne 0$ then $\text{relfinrank } A\,(A \sqcup B) \le \text{relfinrank } A\, B$.

**Proof.** `relrank_sup_left_le` and `Cardinal.toNat_le_toNat`.

## relrank_sup_sup_le

For subfields $A, B, C$ with $[B : A \cap B] < \aleph_0$: $\text{relrank}(A \sqcup C, B \sqcup C) \le \text{relrank}(A, B)$. The docstring gives a counterexample without finiteness: $A = \mathbb Q$, $B = \mathbb Q(t)$, $C = \mathbb R$ in $\mathbb R(t)$, where the left side is $[\mathbb R(t) : \mathbb R] = \mathfrak c > \aleph_0$.

**Proof.** Calc chain: replace $A$ by $A \cap B$ (antitonicity), write $B \sqcup C = ((A \cap B) \sqcup C) \sqcup B$, apply `relrank_sup_left_le` with base $(A \cap B) \sqcup C$, and bound $\text{relrank}((A\cap B) \sqcup C, B) \le \text{relrank}(A \cap B, B) = \text{relrank}(A, B)$ (`inf_relrank_right`).

## relfinrank_sup_sup_le

`relfinrank` version: if `relfinrank A B` $\ne 0$ then $\text{relfinrank}(A \sqcup C, B \sqcup C) \le \text{relfinrank}(A, B)$.

**Proof.** `relrank_sup_sup_le` and `Cardinal.toNat_le_toNat`.

## relrank_pos

Intermediate-field version: for intermediate fields $A, B$ of $E/F$, $0 < [B : A \cap B]$.

**Proof.** `rank_pos`.

## relfinrank_ne_zero_iff

Intermediate-field version: `relfinrank A B` $\ne 0$ iff `relrank A B` $< \aleph_0$.

**Proof.** The `Subfield` lemma.

## relrank_le_of_le_left

Intermediate-field version: $A \le B \Rightarrow [C : B \cap C] \le [C : A \cap C]$ (`@[gcongr]`).

**Proof.** Same tower-law argument as for subfields.

## relfinrank_le_of_le_left

Intermediate-field version: $A \le B$ and `relfinrank A C` $\ne 0$ give $\text{relfinrank } B\, C \le \text{relfinrank } A\, C$.

**Proof.** `relfinrank_dvd_of_le_left` and `Nat.le_of_dvd`.

## relrank_sup_left_le

Intermediate-field version: if `A.relrank B` $< \aleph_0$ then $\text{relrank}(A, A \sqcup B) \le \text{relrank}(A, B)$.

**Proof.** `simpa [relrank]` from the `Subfield` lemma.

## relfinrank_sup_left_le

Intermediate-field version of `relfinrank_sup_left_le`.

**Proof.** `simpa [relfinrank]` from the `Subfield` lemma.

## relrank_sup_sup_le

Intermediate-field version: if `A.relrank B` $< \aleph_0$ then $\text{relrank}(A \sqcup C, B \sqcup C) \le \text{relrank}(A, B)$.

**Proof.** `simpa [relrank]` from the `Subfield` lemma applied to `C.toSubfield`.

## relfinrank_sup_sup_le

Intermediate-field version of `relfinrank_sup_sup_le`.

**Proof.** `simpa [relfinrank]` from the `Subfield` lemma.
