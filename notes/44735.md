Adds the characterisation: for a prime $p$, $p^e \mid n$ if and only if $p \mid \binom{n}{k}$ for every $0 < k < p^e$. It is a consequence of Lucas's theorem, proved in the same file from the one-digit Lucas step `choose_modEq_choose_mod_mul_choose_div_nat` and from `choose_pow_mul_pow_mul_modEq_choose_nat`. Also adds a bibliography entry for Lucas (1878) and cites it in the module docstring.

## pow_dvd_iff_forall_dvd_choose

For a prime $p$ and natural numbers $n, e$: $p^e \mid n$ if and only if $p \mid \binom{n}{k}$ for all $k$ with $0 < k < p^e$. (This includes $n = 0$, where both sides hold.)

**Proof.** ($\Rightarrow$) Induction on $e$, generalising $n$. Since $p \mid n$, Lucas gives $\binom{n}{k} \equiv \binom{0}{k \bmod p}\binom{n/p}{k/p} \pmod p$. If $p \nmid k$ the first factor is $0$. Otherwise write $n = pn'$, $k = pk'$ with $p^e \mid n'$ and $0 < k' < p^e$, and apply the induction hypothesis. ($\Leftarrow$) By contradiction, write $n = p^v m$ with $p \nmid m$. If $v < e$, take $k = p^v$: then $\binom{p^v m}{p^v} \equiv \binom{m}{1} = m \pmod p$, so $p \mid m$, which is a contradiction.
