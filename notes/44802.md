Proves the one-dimensional Brunn–Minkowski inequality $\lambda(A) + \lambda(B) \le \lambda(A+B)$ for arbitrary nonempty $A, B \subseteq \mathbb{R}$ (no measurability needed, $\lambda$ being an outer measure), as a special case of an order-theoretic version for monotone (additive or multiplicative) magmas whose translations do not decrease measure. Supporting lemmas: inner approximation $\mu(S) = \sup_{x\in S}\mu(S \cap (-\infty,x])$, and generalising the instance "$\mathrm{atTop}$ is countably generated in a separable order topology" to subtypes.

## measure_eq_iSup_inter_Iic

For a measure $\mu$ on a preorder $\alpha$ and a set $S$ which is directed (upward) in the induced order and whose `atTop` filter is countably generated:
$$\mu(S) = \sup_{x\in S}\mu\big(S \cap (-\infty, x]\big).$$
No measurability of $S$ is required.

**Proof.** "$\ge$" by monotonicity. For "$\le$" (with $S$ nonempty), $S = \bigcup_{x\in S}(S\cap(-\infty,x])$ is a directed union, so $\mu(S\cap(-\infty,x]) \to \mu(S)$ along `atTop` (`tendsto_measure_iUnion_atTop`), and a limit is bounded by the supremum.

## measure_eq_iSup_inter_Ici

Order dual: for $S$ codirected with countably generated `atBot`, $\mu(S) = \sup_{x\in S}\mu(S \cap [x,\infty))$.

**Proof.** Same proof with `atBot`; registered as the `to_dual` of the previous lemma via `existing`, with a TODO to generate it once `Monotone`/`Antitone` are dualised.

## _root_.PartialOrder.measure_add_measure_le_measure_mul_add_iSup

Let $\alpha$ be a partially ordered magma whose multiplication is monotone on both sides, $\mu$ a measure such that all $(-\infty,x]$ are measurable and left and right translations do not decrease measure ($\mu(s) \le \mu(as)$, $\mu(s) \le \mu(sb)$ for all sets $s$). For nonempty $A$ (directed, countably generated `atTop`) and $B$ (codirected, countably generated `atBot`):
$$\mu(A) + \mu(B) \le \mu(AB) + \sup_{x\in AB}\mu(\{x\}).$$
The additive version (`..._measure_add_add_iSup`) is generated by `to_additive`.

**Proof.** By the two inner-approximation lemmas, it suffices to show $\mu(A\cap(-\infty,a]) + \mu(B\cap[b,\infty)) \le$ RHS for $a\in A$, $b\in B$. Translate: $(A\cap(-\infty,a])\,b \subseteq AB \cap (-\infty,ab]$ and $a\,(B\cap[b,\infty)) \subseteq AB\setminus(-\infty,ab)$; these two pieces overlap at most in $\{ab\}$, and $\mu(AB\cap(-\infty,ab]) + \mu(AB\setminus(-\infty,ab]) = \mu(AB)$ by measurability of $(-\infty,ab]$.

**Check.** Putting a measure-theory lemma in the `PartialOrder` namespace (via `_root_.`) is unusual; a name like `MeasureTheory.measure_add_measure_le_measure_mul_add_iSup` (or one mentioning the order) seems more conventional. The docstring "`μ singleton`" is vague: it is the supremum of the measures of singletons of $AB$.

## volume_add_volume_le

One-dimensional Brunn–Minkowski: for nonempty $A, B \subseteq \mathbb{R}$ (arbitrary, not necessarily measurable), $\lambda(A) + \lambda(B) \le \lambda(A+B)$, with $\lambda$ Lebesgue (outer) measure.

**Proof.** Additive version of the previous lemma; translations preserve Lebesgue measure, and singletons have measure $0$, so the extra supremum vanishes. Directedness and countable generation of `atTop`/`atBot` on subsets of $\mathbb{R}$ come from the linear order and the new subtype instance.

## instIsCountablyGenerated_atTop

Old version removed: the instance "`atTop` is countably generated on a separable space with order topology" is now `instIsCountablyGenerated_atTop_subtype` (for subtypes) plus a new `instIsCountablyGenerated_atTop` (below) deduced from it.

## instIsCountablyGenerated_atTop_subtype

Instance (with order dual for `atBot`): for $\alpha$ a linear order with the order topology and a predicate $P$ such that the subtype $\{x \mid P x\}$ (with subspace topology) is separable, the filter `atTop` on that subtype is countably generated.

**Proof.** The old proof, now run in the subtype: if there is no top element, `atTop` is generated by $\{[x,\infty) : x \in D\}$ for a countable dense $D$ (it uses that $(x,\infty)$ is open in the subspace topology); otherwise `atTop` is $\mathrm{pure}$ of the top element.

## instIsCountablyGenerated_atTop

Instance (with order dual): for $\alpha$ separable with the order topology, `atTop` on $\alpha$ is countably generated (statement as before the PR).

**Proof.** Transport from the subtype instance applied to `Set.univ` along the order isomorphism `univ ≃o α` (`map_atTop`).
