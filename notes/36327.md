Proves Sakai 1.6.1: a (possibly non-unital) C⋆-algebra is unital iff the closed unit ball has an extreme point. The argument runs in four steps:
1. An extreme point $x$ satisfies $xx^*x = x$ (a partial isometry), so $p = x^*x$ and $q = xx^*$ are projections.
2. Formally, $(1-q)A(1-p) = 0$.
3. An approximate unit then shows that $p + q - qp$ is a two-sided identity.
4. Conversely, in a unital C⋆-algebra $1$ is extreme, and so is every unitary.

This extends the existing file on extreme points of the closed unit ball (`Analysis/CStarAlgebra/Extreme.lean`).

## star_self_conjugate_eq_self_of_mem_extremePoints_unitClosedBall

In a non-unital C⋆-algebra $A$, if $a$ is an extreme point of the closed unit ball, then $a a^* a = a$.

**Proof.** It suffices to show $a|a| = a$. We have $a = \tfrac12(2a - a|a|) + \tfrac12 a|a|$, and $a|a|$ lies in the ball. So by extremality it is enough that $\|2a - a|a|\| \le 1$. By the C⋆-identity this norm equals $\|2|a| - |a|^2\| = \|\mathrm{cfc}(t \mapsto 2t - t^2)(|a|)\|$, which is $\le 1$ because the quasispectrum of $|a|$ lies in $[0,1]$.

**Check.** The name ("star_self_conjugate") does not describe $aa^*a = a$ clearly. The TODO says this should become partial-isometry API.

## isStarProjection_star_mul_self_of_mem_extremePoints_unitClosedBall

If $a$ is an extreme point of the closed unit ball of a non-unital C⋆-algebra, then $a^*a$ is a self-adjoint idempotent (a star projection).

**Proof.** `grind` from $aa^*a = a$.

## isStarProjection_self_mul_star_of_mem_extremePoints_unitClosedBall

Same hypothesis: $aa^*$ is a star projection.

**Proof.** `grind` from $aa^*a = a$.

## eq_zero_of_mem_extremePoints_unitClosedBall

Let $x$ be an extreme point of the closed unit ball. Write $p = x^*x$ and $q = xx^*$. Then for every $b \in A$,
$$b - bp - qb + qbp = 0.$$
Formally this is "$(1-q)\,b\,(1-p) = 0$".

**Proof.** By scaling we may assume $a := b - bp - qb + qbp$ lies in the unit ball. Expanding gives $x^*a = 0$ and $a^*x = 0$, so $(x\pm a)^*(x\pm a) = p + a^*a$. Also $p\,a^*a = 0$, so the norm of $p + a^*a$ is the max of the two norms, which is $\le 1$. Hence $x \pm a$ are in the ball, and extremality forces $a = 0$.

**Check.** The name is very generic for a root-namespace lemma, and the conclusion says nothing about $x$ being zero. A name mentioning the expression (or "partial isometry" API) would be clearer.

## CStarAlgebra.right_identity_of_forall_eq_zero

(private) If $t - tp - qt + qtp = 0$ for all $t$, with $p = x^*x$ and $q = xx^*$, then $e = p + q - qp$ is a right identity: $ae = a$ for all $a$.

**Proof.** Apply the hypothesis to the increasing approximate unit $u_\lambda$: $0 = a(u_\lambda - u_\lambda p - qu_\lambda + qu_\lambda p) \to a - ae$.

## CStarAlgebra.right_identity_of_mem_extremePoints

If $x$ is an extreme point of the closed unit ball of a non-unital C⋆-algebra, then $e = x^*x + xx^* - xx^*x^*x$ satisfies $ae = a$ for all $a$.

**Proof.** Combine the two previous lemmas.

## CStarAlgebra.left_identity_of_mem_extremePoints

Same hypothesis: $ea = a$ for all $a$.

**Proof.** Apply the right-identity lemma to the extreme point $x^*$ (the star of an extreme point is extreme) and to $a^*$, then take adjoints.

## CStarAlgebra.one_mem_extremePoints_unitClosedBall

In a unital C⋆-algebra $A$, $1$ is an extreme point of the closed unit ball.

**Proof.** Suppose $1 = c_1x + c_2y$ is a proper convex combination of contractions. Take real parts: $1 = c_1a + c_2b$ with $a = \Re x$ and $b = \Re y$. Spectrally, each $r \in \sigma(a)$ gives $1$ as a proper convex combination of $r$ and a point of $\sigma(b)$, both in $[-1,1]$, so $r = 1$ and $a = 1$. Then $x$ is normal and $\|1 + (\Im x)^2\| = \|x\|^2 \le 1$, which forces $\Im x = 0$.

**Check.** No docstring. Unlike the next lemma, it takes `A` explicitly.

## unitary_mem_extremePoints_unitClosedBall

In a unital C⋆-algebra, every unitary $u$ is an extreme point of the closed unit ball.

**Proof.** Left multiplication by $u$ is a real linear isometric equivalence. It maps the ball to itself and extreme points to extreme points, and $1$ is extreme.

**Check.** No docstring. It is in the root namespace while its sibling is `CStarAlgebra.one_mem_…`.

## CStarAlgebra.isUnital_iff

A non-unital C⋆-algebra $A$ is unital (has a two-sided identity, `IsUnital A`) iff the closed unit ball of $A$ has an extreme point.

**Proof.** (⇒) $1$ is extreme. (⇐) For an extreme point $x$, $x^*x + xx^* - xx^*x^*x$ is a two-sided identity by the left and right identity lemmas.

## CStarAlgebra.isNotUnital_iff

$A$ is not unital iff the closed unit ball has no extreme points.

**Proof.** Negate `isUnital_iff`.

**Check.** No docstring.
