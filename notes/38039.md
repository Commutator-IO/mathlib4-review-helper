Renames the API for extending maps to the Hausdorff completion `UniformSpace.Completion`. The functions `Completion.extension f : Completion α → β` and `Completion.map f : Completion α → Completion β` become `UniformSpace.Function.fromCompletion f` and `UniformSpace.Function.completion f`. Bundled versions follow the pattern `FooHom.fromCompletion` / `FooHom.completion`: `AddMonoidHom.extension` → `AddMonoidHom.fromCompletion`, `NormedAddGroupHom.extension` → `fromCompletion`, `Completion.coeRingHom` / `extensionHom` / `mapRingHom` / `mapRingEquiv` → `UniformSpace.RingHom.toCompletion` / `RingHom.fromCompletion` / `RingHom.completion` / `UniformSpace.RingEquiv.completion`, and `Completion.mapEquiv` → `UniformEquiv.completion`. The lemmas `LipschitzWith`/`Isometry.completion_extension`/`completion_map` become `.fromCompletion`/`.completion`, and `Isometry.extensionHom`/`mapRingHom` become `ringHomFromCompletion`/`ringHomCompletion`. Every old name stays as a deprecated alias. No mathematical content changes.

## *

Rename, mechanical: the declaration either is one of the renamed items above (statement unchanged up to the new names, old name kept as a `@[deprecated]` alias) or only uses the renamed API in its statement or proof. A few `open` lines change to match (`open UniformSpace.Function`, and `Function.curry`/`uncurry` written in full where `open Function` was dropped). What to check:
- every old name has an alias with the right target;
- the new namespaces `UniformSpace.Function`, `UniformSpace.RingHom` and `UniformSpace.RingEquiv` sit next to the root `Function`, `RingHom` and `RingEquiv`. This is a convention choice the reviewer may want to discuss: after `open UniformSpace`, short names like `completion_coe` and `fromCompletion` come into scope.
- most aliases say `since := "2026-06-26"`, but the six `mapRingHom*` aliases say `2026-04-14`. Make the dates consistent.

## Function.fromCompletion

For any map $f : \alpha \to \beta$ into a complete Hausdorff uniform space, its extension to the completion $\widehat{\alpha} \to \beta$. It equals $f$ on $\alpha$ when $f$ is uniformly continuous, and is an arbitrary constant otherwise. Full name `UniformSpace.Function.fromCompletion`. Formerly `Completion.extension`, which is now a deprecated alias.

**Definition.** `cPkg.extend f`, as before. The docstring now says bundled versions must be named `FooHom.fromCompletion`, or `UniformSpace.FooHom.fromCompletion` when it is unclear which completion is meant.

## Function.completion

For $f : \alpha \to \beta$, the induced map $\widehat{\alpha} \to \widehat{\beta}$ on completions (the completion functor on morphisms). Full name `UniformSpace.Function.completion`. Formerly `Completion.map`.

**Definition.** `cPkg.map cPkg f`, unchanged. The docstring adds the same naming rule (`FooHom.completion`).

## Function.completion_comp_completion

If $f : \alpha \to \beta$ and $g : \beta \to \gamma$ are uniformly continuous, then $\widehat{g} \circ \widehat{f} = \widehat{g \circ f}$ on completions. This is the old `Completion.map_comp`, renamed.

**Proof.** Changed: `convert!` from `fromCompletion_comp_completion` (formerly `extension_map`) applied to $\iota \circ g$ and $f$, where $\iota$ is the inclusion into the completion. The old `set_option backward.isDefEq.respectTransparency false` is gone.

## AddMonoidHom.continuous_fromCompletion

For a continuous additive monoid hom $f : \alpha \to \beta$ into a complete Hausdorff group, its extension $\widehat{\alpha} \to \beta$ is continuous. This is the old `AddMonoidHom.continuous_extension`, renamed.

**Proof.** `Function.continuous_fromCompletion`.

**Check.** The old lemma was `@[continuity, fun_prop]`; the new one is only `@[continuity]`. The `fun_prop` attribute is lost, probably by accident.

## algebra

Instance, statement unchanged: the completion of a topological $R$-algebra $A$ is an $R$-algebra, with `algebraMap` given by $A \to \widehat{A}$ composed with $R \to A$.

**Proof.** The `commutes'` proof changed from `simpa only [coe_mul] using!` to `simpa [coe_mul, RingHom.toCompletion] using`, an unfold needed by the rename.

## IsDenseInducing.extendRingHom

Statement unchanged.

**Proof.** In `map_one'` and `map_zero'`, `convert!` becomes plain `convert`. This is unrelated to the rename and looks like stray cleanup.

## Isometry.ringHomCompletion_isometry

For an isometric ring hom $f : \alpha \to \beta$, the induced ring hom $\widehat{\alpha} \to \widehat{\beta}$ is an isometry. This is the old `Isometry.isometry_mapRingHom`.

**Proof.** Changed: `eta_expand; simpa [ringHomCompletion] using h.completion`, i.e. it reduces to the unbundled `Isometry.completion`. The old proof was an explicit induction on pairs of points.

**Check.** The new name puts the conclusion last (`ringHomCompletion_isometry`). The old naming, conclusion first, would give `isometry_ringHomCompletion`, matching `isometry_extensionEmbedding` and similar.
