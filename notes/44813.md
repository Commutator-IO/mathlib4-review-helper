Adds the layer-cake (Cavalieri) formula for $[0,\infty]$-valued functions: $\int f\,d\mu = \int_0^\infty \mu\{f \ge t\}\,dt$. Mathlib already has it for real-valued nonnegative functions (`lintegral_eq_lintegral_meas_le`); this version allows $f$ to take the value $\infty$ and needs only a.e.-measurability.

## lintegral_eq_lintegral_measure_ofReal_le

For a measure $\mu$ and an a.e.-measurable $f : \alpha \to [0,\infty]$:
$$\int^- f\,d\mu = \int^-_{(0,\infty)} \mu\{x \mid t \le f(x)\}\,dt,$$
with $t$ real, embedded via `ENNReal.ofReal`, and the outer integral with respect to Lebesgue measure.

**Proof.** If $f$ is a.e. finite, replace it by `ofReal (f x).toReal` and apply the real version; the sets $\{t \le f\}$ and $\{t \le \mathrm{toReal}\,f\}$ differ by a null set. Otherwise $\mu\{f = \infty\} > 0$, so the left side is $\infty$, and the right side is at least $\int_{(0,\infty)} \mu\{f = \infty\}\,dt = \infty$.
